Smart Apt — 수익 모델

서비스 운영 수익화 방안 기록
v1.0.0 · 2026-08-22 · 아이디어 기록용
1

기본 방향 — 유튜브 모델 (무료 + 광고)

사용자 → 무료로 모든 기능 사용
              ↓
       앱 화면에 광고 노출 (Google AdSense / 카카오 AdFit)
              ↓
       광고 수익 → 운영자
플랫폼특징예상 단가
Google AdSense가장 보편적, 설치 간단, GitHub Pages 허용페이지뷰당 $0.5~2
카카오 AdFit한국 특화, 모바일 강함유사 수준
네이버 애드포스트한국 사용자 최적화유사 수준
2

현실적 수익 계산

월 사용자 수예상 월 수익비고
1,000명2~5만원초기 단계
10,000명20~50만원본격 운영
100,000명200~500만원안정 수익
3

추가 수익 모델 (향후 고려)

Freemium 나중에

광고 제거 유료 구독 (월 N원)
유튜브 프리미엄과 동일 구조.
광고 싫은 사용자 자연스럽게 유료 전환.

커머스 제휴 나중에

항목 등록 시 구매 링크 노출.
쿠팡파트너스·네이버 제휴 등.
구매 발생 시 수수료 수입.

B2B 화이트라벨 나중에

아파트 시행사·부동산 회사에 커스텀 버전 납품.
"○○건설 홈인벤토리" 브랜드.
라이선스 일괄 계약.

서비스 중개 나중에

이사업체·인테리어·보험 연결.
사용자 데이터 기반 맞춤 추천.
중개 수수료 수입.

4

단계별 수익화 로드맵

1단계 무료 서비스 → 사용자 확보
        ↓
2단계 Google AdSense 광고 연결 ← 지금 기록
        ↓
3단계 Freemium 도입 (광고 제거 유료)
        ↓
4단계 커머스 제휴 · B2B 확장

✅ 광고 모델 장점

  • 사용자 무료 → 진입장벽 없음
  • 구현 가장 단순 (코드 한 줄)
  • 사용자 많을수록 자동 증가
  • GitHub Pages에서 완전 허용

⚠️ 광고 모델 단점

  • 초기엔 수익 미미
  • 광고차단기 사용자 수익 없음
  • AdSense 심사 통과 필요
  • 광고가 UX 저해 가능
