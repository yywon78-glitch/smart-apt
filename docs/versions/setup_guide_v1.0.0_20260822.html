프로젝트 개요

Smart Apt는 아파트·가정의 구역별 인벤토리(가전·가구·생활용품 등)를 관리하는 웹앱이다.
서버·DB 없이 GitHub Pages(정적 호스팅)와 개인 Google Drive만으로 운영되며, PC·핸드폰 어디서든 동일한 데이터에 접근할 수 있다.

핵심 파일 설명

파일역할비고
google-auth.js Google Identity Services(GIS) 기반 OAuth 2.0 인증. Access Token을 sessionStorage에 저장해 세션 유지. SmartAuth 전역 객체 제공. Client ID 설정 필요
drive.js Google Drive API v3 래퍼. SmartApt/ 폴더 자동 생성, db.json 읽기/쓰기/초기화(seed). SmartDrive 전역 객체 제공. drive.file 스코프
api-local.js window.fetch 오버라이드. /api/* 요청을 Drive의 db.json 읽기/쓰기로 변환. bom-tree, zones, items, floorplans 등 전체 CRUD 처리. index.html에서 최초 로드
public/index.html SPA 쉘. Google 로그인 UI → 로그인 성공 시 메뉴 표시 → pages/*.html 동적 로드. js 파일 로드 순서 관리. v2.0.0
.github/workflows/pages.yml main 브랜치 push 시 public/ 폴더를 GitHub Pages로 자동 배포. enablement: true 포함
