프로젝트 개요

Smart Apt는 아파트·가정의 구역별 인벤토리(가전·가구·생활용품 등)를 등록·조회·관리하는 웹앱이다.
서버·DB 없이 GitHub Pages(정적 호스팅)와 개인 Google Drive만으로 운영된다.
PC·핸드폰 어디서든 같은 Google 계정으로 로그인하면 동일한 데이터에 접근할 수 있다.

핵심 특징
• 서버 비용 없음 (GitHub Pages 무료 + 개인 Drive 15GB 사용)
• 개인별 독립 데이터 (각자 본인 Drive에 저장 — 데이터 혼용 없음)
• PC에서 등록한 데이터를 핸드폰에서 즉시 확인 가능
• 기존 Apart ERP HTML 5개를 코드 수정 없이 재사용 (fetch 인터셉터 패턴)

트러블슈팅 이력

❌ 문제 1 — 첫 배포 실패 "Get Pages site failed"
원인: actions/configure-pages가 GitHub Pages가 아직 미활성화 상태에서 실패
증상: Actions 탭에서 deploy 단계 4초 만에 실패. "HttpError: Not Found"
해결: pages.yml에 enablement: true 옵션 추가 후 재push
커밋: 7db83f9 "fix: Pages enablement 추가"
❌ 문제 2 — GitHub Pages에서 "연결 끊김" 표시, 저장 버튼 안 됨
원인: git 스테이징 타이밍 문제 — git status에서 'AM public/index.html' 이었는데, 스테이지된 구버전(v1.0.0, localhost:3000 연결용)이 커밋됨. 워킹트리의 신버전(v2.0.0, Google Auth)은 커밋에서 빠짐.
증상: GitHub Pages 접속 시 Google 로그인 화면 대신 "연결 끊김 / 재연결" 표시. 구역 추가 모달 대신 "항목 추가" 모달 열림.
부가 증상: house 노드를 찾지 못해 openNodeMo()에서 openZoneMo() 대신 openItemMo() 호출됨 → 저장 시 parent_item_id 없어서 실패.
해결: 올바른 v2.0.0 index.html을 재stage 후 재커밋, push
커밋: a7c61f5 "fix: index.html v2.0.0 Google Auth 버전으로 교체"
⚠️ 문제 3 — Google Cloud Console 저장 버튼 미작동 (미해결)
원인: 미확인. 브라우저 이슈 또는 폼 유효성 검사 문제로 추정
증상: 승인된 JavaScript 출처에 https://yywon78-glitch.github.io 입력 후 저장 버튼 클릭 안 됨
해결 시도: 다른 URI 필드 클릭 후 재시도, 브라우저 새로고침 후 재입력
현재 상태: 미완료 → GitHub Pages에서 Google 로그인 불가
