1. 개요 및 목표

아파트 한 채에 들어가는 모든 물품을 BOM(Bill of Materials) 구조로 체계화합니다.
구조물→구역→카테고리→물품 의 계층 구조로 분류하여 수량, 단가, 필수여부를 관리합니다.

건축기본시공 시 포함되는 구조 구성품창호, 바닥재, 벽지, 배관, 전기, 냉난방
구역별 필수각 구역에 반드시 있어야 할 물품냉장고, 세탁기, 에어컨, 변기, 세면대
일반 가정용일반적으로 사용하는 가구·가전·생활용품소파, TV, 침대, 청소기, 밥솥

4. 테이블 설계 (5개)

① apt_zone — 구역 마스터

컬럼타입설명
zone_idINT PK구역 ID
zone_codeNCHAR(4)LV, KT, BR1...
zone_nameNVARCHAR(50)거실, 주방...
sort_orderINT정렬순서

② apt_category — 카테고리

컬럼타입설명
cat_idINT PK카테고리 ID
cat_codeNCHAR(6)STRUCT, REQ...
cat_nameNVARCHAR(50)건축기본, 필수가전...
parent_cat_idINT FK상위카테고리 (셀프참조)
sort_orderINT정렬순서

③ apt_item — 물품 마스터

컬럼타입설명
item_idINT PK물품 ID
item_codeNVARCHAR(20)물품코드
item_nameNVARCHAR(100)물품명
cat_idINT FK카테고리
unitNVARCHAR(10)단위 (EA, SET...)
std_priceDECIMAL(12,0)기준단가
brandNVARCHAR(50)브랜드
modelNVARCHAR(100)모델명
specNVARCHAR(200)규격
noteNVARCHAR(500)비고
use_ynCHAR(1)사용여부 Y/N

④ apt_bom — BOM 구조

컬럼타입설명
bom_idINT PKBOM ID
parent_item_idINT FK상위 물품 (NULL=최상위)
child_item_idINT FK하위 물품
zone_idINT FK설치 구역
qtyDECIMAL(10,2)수량
is_requiredCHAR(1)필수여부 Y/N
sort_orderINT정렬순서
level_noINTBOM 레벨 (0=최상위)
noteNVARCHAR(200)비고

⑤ apt_apt — 아파트 기본정보 (확장용)

컬럼타입설명
apt_idINT PK아파트 ID
apt_nameNVARCHAR(100)아파트명
apt_typeNVARCHAR(20)타입 (33평, 42평...)
dongNVARCHAR(10)동
hoNVARCHAR(10)호
area_m2DECIMAL(6,2)전용면적 m²
built_yearINT준공년도
noteNVARCHAR(500)비고

  • └── docs/

6. 구축 순서

단계작업내용
1단계테이블 생성01_create_tables.sql 실행 (apart DB에)
2단계구역 데이터거실/주방/침실 등 12개 구역 입력
3단계카테고리건축기본/필수가전/가구/생활가전/생활용품 분류
4단계물품 마스터전체 물품 코드·명칭·단가·규격 입력
5단계BOM 구조상하위 관계·구역·수량 연결
6단계조회 뷰구역별/타입별 BOM 전개 뷰 생성
